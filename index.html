Wallet signing test

This page checks that Paytaca can sign Holdfast's kind of contract transaction over WizardConnect. It runs on chipnet, Bitcoin Cash's test network, so it only uses free test coins. It is not the Holdfast app.

1 Connect your wallet

Scan the code with Paytaca, or tap the link if the page is open on the same phone.

Open in wallet

Not connected.

2 Get free test coins

Copy this chipnet address, paste it into the faucet, then come back and tap Refresh. About 10,000 test sats is plenty.

Balance: checking...

3 Run the tests

Each button asks Paytaca to approve a transaction. Run A to D in order; E runs on its own. Results stay after a reload, so a test that passed doesn't need running again. On one phone, tap a button and wait until it says Sent before switching to Paytaca.

  1. Not run

    Your wallet creates a small contract holding a state token. This can take two approvals: one to tidy your coins, then the vault.

  2. Not run

    The key test: your wallet signs a spend from the contract.

  3. Not run

    Needs test B's transaction to be in a block first. Wait about 10 minutes after B.

  4. Not run

    Sends the test coins back to your wallet.

  5. Not run

    This page signs with a key it holds, then your wallet adds its signature to the same spend. Holdfast's home code and guardian work this way. Two approvals: one to fund it, then the spend.
