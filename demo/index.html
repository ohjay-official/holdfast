Try it

The full demo opens before judging on Nov 22. It will let you play both sides of a robbery without a wallet. Today you can run the signing tests that came before it.

What the demo will show

  1. Make a vault

    Pick an allowance and a wait. Demo mode uses a pretend wallet, so you don't need one.

  2. Get robbed

    Play the robber: send everything. Watch the allowance leave and the rest start waiting.

  3. Stop it from home

    Switch to your home code and cancel. The vault freezes.

  4. Recover

    Unfreeze with your home code and guardian, and move to a new phone.

Available now

The signing test page connects Paytaca over WizardConnect and runs five real transactions on chipnet: create, contract spend, wait, withdraw and two-key spend. You'll need Paytaca with chipnet turned on and some free test coins.

Open the signing test

In Paytaca, turn on chipnet under Apps, then Settings, then Use Chipnet Network.
