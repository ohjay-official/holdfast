Try it

Play every side of a robbery in about two minutes, with pretend BCH and no wallet. You set up a vault, rob yourself, then stop it from home.

Start the demo

What you'll do

  1. Make a vault

    Pick an allowance and a wait, write down a home code and name a guardian. It all stays in your browser.

  2. Get robbed

    Play the robber: send everything. Watch the allowance leave and the rest start waiting.

  3. Stop it from home

    Switch to your home code and cancel. The vault freezes.

  4. Unfreeze

    Approve as your home code, then as your guardian.

  5. Use the duress PIN

    Lock the phone and open it with the duress PIN. The robber sees only the allowance; the rest freezes quietly.

Real wallet signing

Demo mode follows the vault rules but doesn't touch the blockchain. The signing test page does: it connects Paytaca over WizardConnect and runs five real transactions on chipnet: create, contract spend, wait, withdraw and two-key spend. You'll need Paytaca with chipnet turned on and some free test coins.

Open the signing test

In Paytaca, turn on chipnet under Apps, then Settings, then Use Chipnet Network.
